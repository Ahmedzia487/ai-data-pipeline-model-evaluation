# Project Setup Guide

This guide explains how to set up, run, test, and reproduce the AI-Assisted Data Pipeline & Model Evaluation Dashboard.

## 1. Prerequisites

Make sure the following software is installed:

* Python 3.11
* Git
* Visual Studio Code
* A web browser

Docker Desktop is **not required** for this project.

## 2. Clone the Repository

Open a terminal and run:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ai-data-pipeline-model-evaluation
```

## 3. Create a Virtual Environment

Create a Python virtual environment:

```bash
python -m venv week3_ai
```

### Windows PowerShell

Activate the environment:

```powershell
.\week3_ai\Scripts\Activate.ps1
```

After activation, the terminal should show:

```text
(week3_ai)
```

## 4. Upgrade pip

```powershell
python -m pip install --upgrade pip
```

## 5. Install Project Dependencies

Install all required Python packages:

```powershell
pip install -r requirements.txt
```

The project uses:

* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter
* Hugging Face Transformers
* PyTorch
* Streamlit
* Plotly
* Joblib
* Pytest

## 6. Dataset Setup

The project uses the UCI Student Performance dataset.

The required raw dataset files are:

```text
data/
└── raw/
    ├── student-mat.csv
    └── student-por.csv
```

The Portuguese dataset (`student-por.csv`) is used as the primary dataset for model training.

## 7. Run Data Preprocessing

From the project root:

```powershell
python src/data_preprocessing.py
```

This performs basic data cleaning and creates:

```text
data/processed/student_performance_cleaned.csv
```

Expected output includes:

```text
Original dataset shape: (649, 33)
Missing values: 0
Rows after cleaning: 649
```

## 8. Run Feature Engineering

Run:

```powershell
python src/feature_engineering.py
```

This removes the target and leakage-prone later-period grade columns (`G1` and `G2`), converts categorical variables into numerical features, and creates the feature dataset.

Output:

```text
data/processed/student_performance_features.csv
```

The resulting dataset contains 39 model features.

## 9. Train and Evaluate Models

Run:

```powershell
python src/model_training.py
```

The pipeline trains and evaluates:

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor

Evaluation metrics:

* MAE
* RMSE
* R²

The evaluation results are saved to:

```text
reports/model_evaluation.csv
```

Test predictions are saved to:

```text
reports/test_predictions.csv
```

The selected trained model is saved locally as:

```text
models/best_model.pkl
```

## 10. Run Automated Tests

Run:

```powershell
pytest tests/test_pipeline.py
```

The project currently contains 7 automated tests.

Expected result:

```text
7 passed
```

## 11. Run the Streamlit Dashboard

Start the dashboard with:

```powershell
streamlit run dashboard/app.py
```

Streamlit will provide a local URL, normally:

```text
http://localhost:8501
```

Open the URL in a web browser.

The dashboard includes:

* Dataset overview
* Dataset preview
* Final grade distribution
* Model comparison
* MAE and RMSE visualization
* R² comparison
* Actual vs. predicted grades
* Feature importance
* Interactive student performance prediction

## 12. Complete Pipeline

For a fresh setup, run the following commands in order:

```powershell
python src/data_preprocessing.py
python src/feature_engineering.py
python src/model_training.py
pytest tests/test_pipeline.py
streamlit run dashboard/app.py
```

## 14. Troubleshooting

### Virtual environment is not activated

Run:

```powershell
.\week3_ai\Scripts\Activate.ps1
```

### PowerShell blocks environment activation

If PowerShell displays an execution-policy error, run:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Then activate again:

```powershell
.\week3_ai\Scripts\Activate.ps1
```

### Streamlit command is not recognized

Make sure the virtual environment is activated and run:

```powershell
pip install streamlit
```

Then:

```powershell
streamlit run dashboard/app.py
```

### Pytest command is not recognized

Install pytest:

```powershell
pip install pytest
```

Then:

```powershell
pytest tests/test_pipeline.py
```

## 15. Important Notes

The `data/processed/` and `models/` directories are excluded from Git tracking through `.gitignore`.

They can be regenerated by running:

```powershell
python src/data_preprocessing.py
python src/feature_engineering.py
python src/model_training.py
```

The project is designed as an educational and analytical student performance prediction system and should not be treated as a definitive assessment of individual student outcomes.
